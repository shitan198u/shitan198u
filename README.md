### Summary

Linux Systems Engineer and Open-Source Software Developer specializing in systems automation, desktop application architecture (Python/Qt), containerized infrastructure, and Generative AI / RAG workflows. Focused on engineering reliable, high-performance software with clean architectures and automated delivery pipelines.

- **Systems & Architecture**: Deep familiarity with Linux environments (RHEL, Ubuntu, Arch), kernel mount lifecycle management, systemd services, and desktop integration.
- **Desktop & Applications**: Designing production cross-platform GUI applications with PySide6/Qt, native compiler packaging (Nuitka), and automated release workflows.
- **Generative AI & Data**: Developing multi-modal RAG systems with LangChain, local LLM inference (Ollama), and cloud API integrations (Groq, Gemini, OpenAI).
- **Cloud & DevOps**: Provisioning and managing containerized workloads using Docker, Kubernetes, Terraform, Microsoft Azure, and GitHub Actions CI/CD.
